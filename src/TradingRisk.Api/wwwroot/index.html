    READ THE CODE, THEN CHANGE IT

    Three boundaries to notice

    01 / HTTP

    The browser speaks contracts

    Forms become JSON request records. Problem Details returns predictable validation errors without exposing internal exceptions.

    wwwroot/js → Controller
    02 / APPLICATION

    Handlers coordinate the use case

    The controller maps and delegates. Handlers load the portfolio, create domain inputs, invoke policy, and map the result.

    Controller → Handler → Port
    03 / DOMAIN

    The model protects the math

    Value objects normalize IDs, aggregates protect invariants, and the pure calculator has no dependency on HTTP or storage.

    Portfolio + Scenarios → Report

    Educational implementation only. Not suitable for trading, limits, capital, or regulatory reporting.
